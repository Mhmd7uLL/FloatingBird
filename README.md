# Floating "Hand Tracking" Bird

Game 2D penggunaan fitur AI untuk interaktivitas dalam bermain. Memberikan pengalaman bermain seperti game OG nya yaitu "FlappyBird"

# Tech Stack
1. Language: JavaScript
2. Framework: React
3. Model: MediaPipe Hand LandMarker

# How to Run Project
1. Clone repository ini
2. Install dependency yang dibutuhkan dengan command

```bash
cd flappyHand
npm install
```
3. Jalankan Frontend

```bash
npm run dev
```
